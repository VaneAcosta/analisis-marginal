# Laboratorio de Análisis Marginal

Web interactiva para la Unidad V de **Contabilidad Gerencial**.

**Docente:** C.P. María Vanesa Acosta

## Contenidos
- Costos fijos y variables
- Contribución marginal y margen de contribución
- Punto de equilibrio físico y monetario
- Margen de seguridad
- Análisis de alternativas
- Costos e ingresos diferenciales
- Costos hundidos
- Modo desafío con 5 niveles

## Publicación
Este repositorio está preparado para publicarse directamente con **GitHub Pages** desde la rama `main` y la carpeta `/(root)`.

El archivo principal debe llamarse `index.html`.
